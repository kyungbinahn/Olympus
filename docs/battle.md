> **2026-10-22: 스테이지 사다리는 닫았다**(결정 C — 사건 중심). 전투 엔진·병사 모델은 1장 "300 vs 1"이 그대로 쓴다
> ([`chapter1-300.md`](chapter1-300.md)). 그리기·재생은 `BattleArena`로 떼어 냈고 전선 씬과 기지가 같이 쓴다.

작성 2026-10-20. 근거: [`topforce-early-game.md`](topforce-early-game.md) 3-1절 B(전선 스테이지 고리), 8-1절 대응표.

## 한 장 요약

| 탑포스 | 올림푸스 |
|---|---|
| 성문 밖 전선, `FIGHT 45` 버튼 | 하단 **"전선"** 버튼(본부 Lv.2에 생김) → 다음 스테이지 화면 |

| 영웅 5칸 편성 + 자동 전투 | **군대가 건물에서 나온다**(영웅은 아직 없음) + 자동 전투 |
| 미션 진도가 기지 레벨 조건(미션 46) | 본부 Lv.3·4·5 조건에 **스테이지 2·5·10 클리어** |

## 전투 규칙 (Core `BattleSimulation`)

- 50ms 한 걸음씩. 가장 가까운 적에게 걸어가 사거리에 들면 간격마다 친다. 겹치면 서로 밀어낸다.
- 근접은 앞줄, 활은 뒷줄. 90초 안에 못 끝내면 진다.
- **무작위가 없다** — 같은 군대·같은 스테이지면 결과가 늘 같다. 그래서
  - 화면은 시뮬레이션을 재생만 하고, 결과는 Core(`BattleService.Fight`)가 같은 입력으로 다시 돌려 적용한다.
  - 시험·봇이 화면 없이 수천 판을 돌린다.
- 전투력 숫자 = 체력의 절반 + 초당 피해 × 10. 표시용이고 승패는 시뮬레이션이 정한다.

## 화면 (병사 모습)

애니메이션 모델이 없어서 **도형 병사**로 섰다 — 몸통(아군 파랑 / 적 붉은 갈색) + 머리 + 종류별 소품
(호플리테스 방패·창, 궁수 활, 거인 몽둥이, 키클롭스 외눈). 애니메이션 대신:

- 걸을 때 위아래로 흔들림, 칠 때 앞으로 찌름, 맞으면 하얗게 번쩍, 죽으면 옆으로 넘어져 가라앉음
- 궁수·돌팔매는 화살이 포물선으로 날아감
- 다친 병사만 머리 위에 체력바

**실제 모델(2026-10-20 적용)**: Quaternius *Universal Base Characters* 남자 몸 + *Universal Animation Library*
(둘 다 **CC0** — 상업용 무료, 표기 의무 없음). `Assets/Art/Characters/Quaternius/`, 원본 zip은
`D:\OlympusArt\character\_downloads\quaternius\`. 쓰는 동작: 대기 `Idle_Loop`, 행군 `Jog_Fwd_Loop`,
공격 `Sword_Attack`(호플리테스) / `Punch_Cross`(거인·키클롭스) / `Spell_Simple_Shoot`(궁수·돌팔매), 쓰러짐 `Death01`.
진영은 몸 위에 색을 덧칠해 가른다(아군 푸른빛, 적 붉은빛). **맨몸 임시 모델이다** — 갑옷·방패가 없어
호플리테스와 궁수가 같은 몸이다. 그리스 병사 모델이 나오면 아래 칸만 갈아 끼운다.
`Olympus/Setup/전투 씬 만들기`가 모델·동작·재질을 자동으로 잇는다(`BattleSoldierSetup`).

**아트 납품 모델(2026-10-22)**: 호플리테스(`Assets/Art/Characters/Hoplite/`, 창·방패·볏·망토 팀색)와
거인 몹(`Assets/Art/Characters/Giant/`, 맨손, 판정 반지름 1.1 → 키 약 5m)이 임시 몸을 대신한다. 둘 다 같은 뼈대라
동작은 위 Quaternius 클립을 그대로 쓴다. 궁수·돌팔매 거인·키클롭스는 아직 임시 몸.

**실제 모델 끼우기**: 전투 씬의 `BattlePresenter` → `Unit Models`에 `unitId`(hoplite·archer·giant_brute·
giant_slinger·cyclops)와 모델을 넣으면 그 종류만 모델로 바뀐다. 모델에 Animator가 있으면

## 거인은 적게 (2026-10-22, 형님)

컨셉이 "300 vs 1"이라 거인은 **한 화면에 1~3마리**, 한 마리가 무겁다. 떼로 몰려오면 거인이 아니라 잡몹이다.

| | 체력 | 공격 | 간격 | 반지름(키) |
|---|---|---|---|---|
| 거인 | 800 | 40 | 1.4초 | 1.1 (약 5m) |
| 돌팔매 거인 | 260 | 22 | 1.6초 | 0.8 |
| 키클롭스(보스) | 4000 | 90 | 1.8초 | 1.6 |

스테이지는 거인 1 → 거인 1 + 돌팔매 1 → 거인 2 → … 최대 거인 3 + 돌팔매 3, 세기는 `multiplier`로 올린다.
배수가 1보다 크면 몸도 커진다(최대 1.6배). 줄 간격은 그 줄의 가장 큰 몸에 맞춰 선다.
봇 결과는 바꾸기 전과 거의 같다: 본부 Lv.4 10.5분, Lv.5 41.8분, 스테이지 10을 18.8분에.
거인 한 방이 한 명만 치는 것은 아직이다 — 광역(휩쓸기) 공격은 1장 "300 vs 1"에서 넣는다.
