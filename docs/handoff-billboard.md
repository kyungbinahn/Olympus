# 인계 — 건물을 사전 렌더 판넬(빌보드)로 바꾸는 검토

작성 2026-09-18. 이 문서는 **다음 세션이 이어받기 위한 것**이다.
앞 세션에서 한 일과, 이어서 판단해야 할 것을 적었다.

## 하려는 것

씬에 3D 메쉬를 세우는 대신, **건물을 미리 렌더한 그림 한 장**으로 바꾼다.
평면 판넬(쿼드)에 그 그림을 붙여 세운다.

동기는 화질이다. 지금 들어간 모델은 Tripo 생성물(140만 삼각형)을 14만까지 줄인 것이라
가까이서 보면 표면이 각지고, 줄일수록 더 나빠진다. 반면 **미리 렌더하면 폴리곤 수가
화질에 아무 영향이 없다** — 오프라인 렌더라 원본 140만 그대로 써도 비용이 0이다.

## 왜 이 프로젝트에 특히 잘 맞나

카메라 각도가 **고정**이다. `TerritoryCamera`의 pitch 50° / yaw 45°는 상수이고
팬·줌만 한다. 건물도 회전하지 않는다. 즉 **모든 건물이 항상 같은 각도로만 보인다** —
그 각도에서 한 번 찍어 두면 런타임에 3D가 필요 없다.

효과:
- 삼각형 14만 → 사실상 0 (쿼드 21개)
- 화질은 오프라인 렌더 품질 그대로 (그림자·AO·조명 다 구워 넣을 수 있다)
- 21종을 넘어 건물이 늘어도 런타임 비용이 거의 안 는다

## 이어서 판단해야 할 것 (중요한 순서)

### 1. 카메라를 직교(orthographic)로 바꿀 것인가 ← 제일 먼저 정할 것

지금 기지 카메라는 **원근(perspective, FOV 45)**이다. 원근 카메라에서는 화면 중앙의
건물과 가장자리의 건물이 **서로 다른 각도로 보인다**. 판넬은 한 각도로만 찍혀 있으므로
가장자리 건물이 어색해진다.

- 직교로 바꾸면 화면 어디에 있든 각도가 같아서 판넬과 완벽히 맞는다.
  이 장르(쿼터뷰 기지 빌더)에서 흔한 선택이고, **월드맵 카메라는 이미 직교다**.
- 원근을 유지하려면 가장자리 왜곡을 눈으로 보고 받아들일 수 있는지 판단해야 한다.

→ **판넬로 갈 거면 직교가 거의 전제 조건이다.** 이것부터 결정할 것.

### 2. 줌 범위와 해상도

`TerritoryCamera`의 거리는 12~90이다. 제일 당겼을 때 건물이 화면을 크게 차지하면
판넬 해상도가 부족해 뭉개진다. 정할 것:
- 건물 한 채당 렌더 해상도 (예: 1024², 2048²)
- 최소 줌 거리를 제한할지

### 3. 단계별 그림이 필요하다

건물은 **폐허 / 공사 중 / 완성** 세 단계가 있다. 지금은 완성 모델만 있고 나머지는
그레이박스 큐브다. 판넬로 가면 단계마다 그림이 필요하다(21종 × 3 = 63장) —
아니면 지금처럼 폐허·공사 중은 큐브로 두고 완성만 판넬로 할 수도 있다.

### 4. 그리는 순서(정렬)와 겹침

판넬은 평면이라 서로 겹칠 때 앞뒤 순서를 직접 정해야 한다. 카메라가 고정이므로
**격자 좌표로 정렬하면 된다**(뒤쪽 칸부터). 알파 컷아웃 + 깊이 쓰기로도 풀린다.

### 5. 그림자

렌더에 구워 넣을지, 별도의 둥근 그림자를 바닥에 깔지. 구워 넣으면 공짜지만
시간대 연출(낮/밤)을 넣을 때 굳어 버린다.

## 렌더는 어떻게 뽑나

Blender를 이미 파이프라인에서 쓰고 있다(`D:\OlympusArt\background\`):
- `glb-to-fbx.py` — 메쉬 변환 (Blender)
- `extract-glb-textures.py` — 텍스처 원본 바이트 추출 (순수 파이썬)

여기에 **렌더 스크립트를 하나 더 붙이면 된다**. 각 건물을 게임과 같은 각도
(pitch 50° / yaw 45°, 직교로 정할 경우 직교 카메라)로 배치하고 알파 포함 PNG로 출력.

각 건물 폴더에 이미 `render/` 가 있고 Cycles 플랫 렌더 4각도가 들어 있다 —
그 스크립트를 참고하면 빠르다.

## 아직 안 정한 것 (판넬과 별개)

1. **기지 저작 툴** — 씬에서 건물을 옮기고·돌리고·크기 조정한 뒤 **같은 JSON에 저장**하는
   에디터 툴. 프리팹이나 씬에 저장하는 방식은 피할 것 — 뉴포리아의 위치 저작 씬이
   그렇게 죽었다(`project-layout.md` 규칙 1).
   판넬로 가면 "크기·회전 보정"의 성격이 달라지므로 **판넬 결정 후에 만드는 게 낫다.**
2. **건물 레벨 업그레이드** — 뉴포리아의 뼈대는 "본부 레벨 = 모든 건물의 상한"
   (그 조건이 1,105회 등장). 지금 올림푸스는 복구하면 Lv1이고 끝이라 그다음이 없다.
   이 장르의 핵심 루프라 판넬과 무관하게 언젠가 필요하다.
