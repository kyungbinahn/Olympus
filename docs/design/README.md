## 규칙

1. **각 문서의 목적은 앞 문서들에 쌓인 미결을 닫는 것이다.** 머리에 "이 문서가 닫은 미결"을 적는다.
2. **숫자는 추측하지 않는다.** 실측(`00`)에서 가져오거나, 봇 시험(`tools/DomainTests/RealData`)으로 확인한다. 문장마다 출처 태그를 붙인다:
   - `[실측]`(탑포스 원문은 `[관찰]`) 화면·테이블에서 직접 읽은 값 · `[추정]` 파일 이름에서 짐작(숫자 근거로 안 씀)
   - `[가져옴]` 레퍼런스 구조를 그대로 · `[고침]` 레퍼런스를 바꿔서 · `[제안]` 아직 형님 결정 전
   - `[설계]` 여기서 정한 기준선(튜닝 전제) · `[검증]` 계산·봇·시험으로 확인한 값
   - `✅확정 (날짜)` 형님이 정한 것
3. **결정은 선택지를 표로 놓고 기각 사유를 적는다.** 채택한 안 옆에는 **"그 대가로 잃는 것"** 을 반드시 적는다.
4. **문서 끝에 세 묶음**: `처리 결과` / `형님 확정 필요` / `남은 것(선행 조건 대기)`. 결정되면 ✅확정으로 옮기고 미결에서 뺀다.
5. **문서끼리 번호로 참조한다**(`` `03` 4절 ``). 한 문서가 바뀌면 그걸 인용한 문서도 **같은 커밋에서** 고친다.
6. **틀렸으면 지우지 말고 교정 기록을 남긴다**(`⚠️ 날짜 교정 기록`). 무엇이 틀렸고, 왜 틀렸고, 지금 값이 무엇인지.
7. **문서 끝에 `부록 — 핵심 상수` 표.** 숫자의 원본은 이 표다. `Assets/Data/*.json`은 그걸 옮긴 것이고, 숫자를 바꾸면 같은 커밋에서 표도 고친다.
   (표를 시험으로 묶는 일은 아직 — `02` 10절 남은 것)
