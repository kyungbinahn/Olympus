## 0. 한 장 요약

1. **탑포스는 "방치형 군인 공장"으로 시작해서 SLG로 변신하는 게임이다.** 패키지 이름부터
   `idle`이고, 빌드 경로는 `slg_cicd_release`다. 처음부터 SLG로 기획하고 앞에 방치형을 붙였다.
2. 초반은 세 고리가 맞물린다: **시설 업글(초 단위) → 전선 자동전투(코인) → 스테이지(영웅)**.
   하단 퀘스트 바 한 줄이 셋을 번갈아 시킨다.
3. **기지 Lv.3→4가 SLG로 넘어가는 문이다.** 2분 타이머, 가속권 튜토리얼, "지휘 센터" 컷신,
   바닥에 격자가 깔리고, 건설 대기열·우편·인벤토리가 생긴다. 다음 레벨 조건은 "선행 건물 레벨"로 바뀐다.
4. **BM은 SLG 정석 풀세트가 이미 다 들어 있다**(UI 패널 89종): 첫충전, 접속 팝업 영웅팩,
   배틀패스 6종, 월정액·주간카드, 일일 필구, VIP, 뽑기, 스킨, 가속, 보호막, 연맹 열차 VIP 등.
   **첫 과금 미끼는 앱을 켤 때마다 뜬다**(₩1,500 UR 영웅).
5. 기지 안에 **"전투 구역 → 정리된 구역" 복구 연출**이 있다 [추정]. 올림푸스의 황폐→복구와 같은 발상이다.
6. 개발: **Century Games**(화이트아웃 서바이벌·킹샷 개발사) 계열, 스튜디오명 *Top Studio*,
   **Unity 2022.3.62f2** — 뉴포리아와 같은 엔진 버전이다.
7. 올림푸스 추천: **지금 방향(복구형 SLG)을 유지하고, 탑포스의 장치만 빌린다** —
   퀘스트 바, 본부 레벨 3조건, 가속권 튜토리얼, 기능 단계 해금, 가벼운 전선 스테이지.
8. **[신규 계정으로 확인] 첫 과금 장치는 "빌려 쓰게 하고 → 회수하고 → 판다"다.**
   튜토리얼 보스전에 UR 영웅 나탈리를 Lv.10 게스트로 붙여 피해의 83%를 넣게 하고, 이기자마자
   ₩1,500 나탈리 팩을 띄우고, 이야기로 나탈리를 떠나보낸 직후 **상점·첫 충전 버튼이 처음 생긴다.**
   첫 충전 버튼 얼굴이 나탈리다. 상점·과금 버튼은 이 순간(약 20분)까지 화면에 없다.
9. **[신규 계정] 첫 20분은 기다림이 0이다.** 기지 Lv.1→2는 조건 창도 타이머도 없이 즉시,
   Lv.2→3은 5초. 시설 업글은 2~8코인·4~7초. 첫 분 단위 대기는 Lv.3→4(2분)에서 처음 나온다.

- 별(10레벨마다) 지점에서 단가가 크게 뛴다. Lv.40 별에서는 **장비 업그레이드에 짧은 타이머**가 붙는다.
- 별을 받을 때마다 업그레이드 창이 닫히고 별 말풍선을 눌러야 한다 → **연타를 끊어 보상 연출을 보게 한다.**

### 3-1. 세 개의 고리 [관찰]

**A. 기지 안 "공장" 고리 (방치형)**
- 초록 병사들이 줄을 서서 시설을 차례로 돈다: 소총 → 수류탄 → 구급키트 → (전차고).
- 노란 일꾼이 시설에서 만든 장비를 날라 병사에게 쥐여 준다.
- 장비를 받은 병사는 성문 밖으로 나가 전선에서 **저절로** 싸운다. 이기면 코인이 떨어진다.
- 코인으로 시설을 올린다. **한 번에 40~64코인, 대기 3~7초.** 연타하면 바로 오른다.
- 시설 화면: `Level 30 / 수류탄 / ★★★☆☆ / 생산량 181 / 5s / [40코인]`.
- **시설 10레벨마다 별 1개.** 별이 차면 시설 장비가 한 단계 바뀐다("장비 업그레이드 Lv.3 폭파 수류탄").

**B. 전선 "스테이지" 고리 (PvE)**
- 성문 밖 전선에서 적 웨이브가 계속 온다(5칸 진행바: 4개 깨면 보스).
- 전선 옆 `FIGHT 45` → 영웅을 **5칸**에 배치 → 자동 전투 → 영웅 스킬은 쿨타임으로 자동 발동.
- 전투 전 화면에 **내 전투력 11.78K vs 적 11.87K**를 나란히 보여 준다.
- 보상(미션 45): 코인 800, 경험치 1.8K, **새 영웅 SR 사만다**.
- 결과 화면: 가한 피해량 / 받은 피해량 영웅별 막대.

**C. 기지 레벨 고리 (진척)**
- "Lv.3 기지" 창 = 별로 여는 **업그레이드 길(마일스톤)**. 칸마다 영구 버프:
  - 12 소총 조립 I(소총 제작 속도↑) / 13 병사 집결 VI(조끼 제작↑) / 14 긴급 명령 III(전 병사 이동속도↑)
  - 15 고성능 폭약 I(수류탄 제작↑) / 16 병사 집결 VII(**+1 군인**)
- 칸을 다 열면 상자 보상(다이아 20)과 함께 **기지 업그레이드 버튼**이 열린다.
- 아직 안 닫은 칸은 `이동` 버튼으로 해당 시설로 카메라가 날아간다.

### 3-2. 퀘스트 바 [관찰]

하단에 **딱 한 줄**. 오늘 받은 순서:

`구급키트 Lv30 → 미션 35 → 소총 Lv40 → 미션 40 → 수류탄 Lv40 → 구급키트 Lv40 → 미션 45 → 전차 Lv40`

- **시설(A)과 스테이지(B)를 번갈아** 시킨다 → 한쪽만 앞서 나가면 다른 쪽이 막힌다.
- 누르면 해당 위치로 카메라 이동 + 화살표. 완료하면 바로 다음이 뜬다(쉬는 틈이 없다).

### 3-3. 영웅 [관찰]

- 영웅 목록 16명 이상. 등급 SR / SSR / UR(색: 보라·주황·금).
- **3계열**: 보병(헬멧) · 전차 · 항공. 계열 아이콘이 카드 왼쪽 아래.
- 역할 아이콘(방패=탱커, 번개=딜러 등)이 카드 왼쪽 위.
- 획득: 조각 **0/10** 모으기. 첫 영웅(빅터)·두 번째(사만다)는 스테이지 보상으로 그냥 준다.
- **영웅 최대 레벨 = 기지 레벨에 묶임**: Lv.3 → 10, Lv.4 → 15, Lv.5 → 25.

### 3-4. 이야기 장치 [관찰]

- 스테이지 보상으로 받은 영웅이 **기지 밖에 `?` 말풍선을 단 NPC로 서 있다.**
- 누르면 대사: 사만다 "레드 군단이 제 야영지를 공격했습니다. 거대한 전쟁 기계를…" →
  빅터 "레드 군단이 새로운 힘을 손에 넣은 것 같습니다. 그 배후의 진실을 밝혀내겠습니다."
- 다음 스테이지들에 대한 **동기(떡밥)** 를 던진다. 데이터에 `story_rescuehero_phase1_1/2`
  (영웅 구출 이야기), `story_beginning`, `plotlinespanel`이 있다 [추정].

### 3-5. 기지 밖과 실시간 위협 [관찰]

- 기지 바깥은 **안개**로 덮여 있다(`cityfog`). 반대편 성문 밖이 전선.
- 기지 근처로 **적 비행선**이 날아와 폭격하는 장면이 수시로 나온다 → 아군 병력이 맞서 싸운다.
  "가만히 둬도 화면이 바쁘다"는 볼거리 역할.

## 4. SLG로 넘어가는 순간 (기지 Lv.3 → Lv.4) [관찰, 직접 통과]

### 4-1. 레벨업 조건

| | Lv.3 → 4 | Lv.4 → 5 |
|---|---|---|
| 별 | 16/16 | 25 |
| 코인 | 1K | 5K |
| 추가 조건 | **미션 46 클리어** | **Lv.2 모집 센터** |
| 시간 | 2분 | 3분 |
| 보상 | 영웅 최대 Lv 10→15, 전투력 2700→3600, 경험치 10K, 신규 건물 헬리콥터·모집 센터 | 영웅 최대 Lv 15→25, 전투력 3600→4500, 경험치 15K |

→ 조건 문법이 **"스테이지 진도" → "선행 건물 레벨"** 로 바뀐다. 뉴포리아에서 본
"본부 업글에 특정 건물 레벨 게이트"(10-7 발견 3)와 같은 구조로 들어간다.

### 4-2. 전환 순서 그대로

1. 업그레이드를 누르면 **첫 분 단위 타이머(2분)**. 그때까지 대기는 전부 초 단위였다.
2. 튜토리얼 손가락이 타이머 → 가속 버튼을 누르게 한다.
3. **가속 창**: 빠른 사용 / 즉시 완료(다이아 7) / 15분 건설 가속(보유 1) / 5분 건설 가속(보유 5) / 1분…
   → 손가락이 **5분권 사용**을 시킨다. 가속권을 미리 쥐여 주고 쓰는 법부터 가르친다.
4. 대사(병사 "유닛"): "보고! **지휘 센터** 건설 조건을 충족했습니다."
5. 대사(지휘관): "더 많은 **무기 공장**을 건설해 앞으로의 전투에 대비할 수 있겠군."
6. 손가락이 **거대한 선물상자**(깃대 자리)를 누르게 한다.
7. **컷신**: 카메라가 멀리 빠졌다가 → 기지 바닥에 **격자(칸)가 깔리고** → 지휘 센터가 세워지고 →
   깃발이 바뀌고(UN 깃발) → 보병 두 줄과 전차 넷이 **열병식**. (`ageupdate_timeline_3`로 보인다)
8. "기지 업그레이드 4" 화면 + 신규 건물 카드.
9. **별점 평가 팝업**("별 5개 평가") — 감정이 가장 좋은 순간에 띄운다.
10. 대사: "공중 지원을 위한 **항공 유닛**이 해제되었습니다!"
11. 성벽이 넓어지고 새 빈 칸에 망치 아이콘 → 누르면 헬기장이 **선물상자로 "도착"** → 열면 헬기.
12. **HUD가 바뀐다**: 왼쪽 위 건설 대기열 `망치 0/1`, 오른쪽 `우편`, `인벤토리` 버튼 신설.
    시설마다 빨간 `↑` (업그레이드 가능) 표시가 붙는다.
13. 지휘 센터를 누르면 이제 **건물 위 업그레이드 버튼** → SLG식 본부 창.

### 4-3. 이게 왜 잘 만든 전환인가

- **스위치 한 번이 아니다.** 타이머 → 가속권 → 건설 대기열 → 선행 건물 조건을 **하나씩** 끼워 넣는다.
- 플레이어는 **이미 커진 계정**(영웅 2명, 전투력 3.6만, 가속권 여러 장)을 들고 들어간다.
- 새 문법이 들어오는 순간마다 **선물상자·컷신·열병식**으로 포장해서 "손해"가 아니라 "승진"처럼 느끼게 한다.
  (실제로는 대기 시간과 과금 지점이 생기는 순간이다.)

### 6-3. BM 흐름으로 읽으면

1. **방치형 구간(Lv.1~3)**: 과금이 거의 필요 없다. 대신 **첫 충전 미끼를 계속 보여 준다**(₩1,500, 가치 10200%).
   이 단계의 목표는 매출이 아니라 **"결제 카드 등록" 한 번**이다.
2. **전환 직후(Lv.4~)**: 분 단위 타이머 + 가속권 + 다이아 즉시 완료가 등장 → **시간 = 돈** 문법을 가르친다.
   다이아를 마일스톤 상자로 먼저 쥐여 주고, 가속권도 미리 줘서 "써 보는 경험"부터.
3. **SLG 본편**: 패스 여러 개 + 월정액 + 일일 필구 + VIP 로 **매일·매주·매달 내는 돈**을 깐다.
   그 위에 **PvP·연맹 이벤트(KvK, 도시전, 군비경쟁)** 가 경쟁 소비를 만들고, 보호막·가속·자원 구매가 소모된다.
4. **소셜 레버**: 열차 VIP, 홍바오, 연맹 선물 → 한 명의 결제가 연맹 전체 이익이 되게 만든다.

## 7. 기능적으로 무엇이 무엇을 "미리 가르치나"

| 초반 방치형 장치 | 나중 SLG에서 대응하는 것 | 몸으로 배우는 것 |
|---|---|---|
| 시설 레벨업 (코인, 초 단위) | 건물 업그레이드 (자원, 분~시간) | 자원을 써서 숫자를 올린다 |
| 전선 자동전투가 코인을 떨굼 | 자원 생산 건물·월드맵 채집 | 소득은 시간이 만든다 |
| `FIGHT` + 영웅 5칸 배치 + 전투력 비교 | 몬스터·SLG 전투 편성 | **전투력 숫자 = 이길 수 있나** |
| 영웅 3계열(보병·전차·항공) | 병종·병과 | 편성에 종류가 있다 |
| 별 마일스톤 (속도+, 병사+1) | 연구(테크) | 영구 버프를 고른다 |
| 기지 레벨 3조건 | 본부 게이트(선행 건물) | 한쪽만 올려서는 못 간다 |
| 2분 타이머 + 가속권 튜토리얼 | 가속 경제(과금의 중심) | 기다림은 줄일 수 있다 |
| 기지 밖 안개 + 성벽 확장 | 구역 해금·월드맵 | 바깥에 더 있다 |
| 기지를 공격하는 적 비행선 | 월드맵 PvP 습격·보호막 | 내 기지는 공격받을 수 있다 |
| 영웅 NPC 대사(레드 군단) | 세계관의 적·이벤트 보스 | 싸울 이유 |

**전투력 숫자가 화면 맨 위에 항상 떠 있다.** 어느 고리를 돌려도 이 숫자가 오른다.
방치형 단계에서 "전투력 = 진도"를 가르쳐 두고, SLG에서는 이 숫자가 **랭킹·서버전·PvP의 화폐**가 된다.

### 10-2. ★뉴포리아 건물은 격자 위에 없다

가장 중요한 발견이다. `FloatingIslandBuildData.StartPosition`이 격자 좌표가 아니라
**소수점 월드 좌표 문자열**이다:

```
"0_0_0"                      MainBuilding
"-17.15_0.4375_-46.075"      SubBuilding
"-21.1975_0_-32.5325"        WallManager
"99_0_99"                    SurvivorBuilding  ← "아직 안 놓음" 매직 센티넬
```

그래서 그쪽 배치 검증이 격자 점유가 아니라 float 바운즈 스캔 + 쌍별 겹침 비교다.
`TerritoryPlacementValidator`가 전 건물을 훑어 min/max를 구하고 여백 ±15를 더하고
그 결과를 세션 단위로 캐시하는 구조, 그리고 거기서 파생된 함정들
("영지 재진입 후 배치가 안 된다", "드래그가 안 잡히는데 로그가 한 줄도 안 남는다")이
모두 이 자유 배치 전제에서 나온다.

→ **좌표를 그대로 베낄 수 없다.** 격자 레이아웃은 새로 저작해야 한다.
→ 대신 우리 격자 방식에서는 그 함정군이 원리적으로 발생할 수 없다.

### 10-7. 뉴포리아 건물 수치 (2026-09-14 조사)

올림푸스의 임시 밸런스가 무근거였다. 뉴포리아의 실제 라이브 테이블을 조사해서
그 곡선 위에 다시 올렸다. 여기 적힌 게 `Assets/Data/building-defs.json`의 근거다.

#### 데이터가 어디 있나

- `C:\Users\user\dfw-resource\gamedata\json\data\` (클라이언트에서 `dfw-client\JsonData`로 심볼릭 링크)
- `FloatingIslandBuildLevelData.json` — **1,975행**. 레벨별 비용·시간·조건·효과. 여기가 본체다.
- `FloatingIslandBuildData.json` — 건물 종류·해금 조건·풋프린트
- `ScheduleData.json` — 서버 오픈 후 D+N 컨텐츠 일정 (520행)
- 원본 xlsx는 그 레포에 없다(빌드된 json만 배포). 수식·기획 주석은 볼 수 없다.
- **비용·시간은 서버가 주는 값이 아니라 클라이언트가 읽는 정적 테이블이다.** 서버는 같은 테이블을 공유한다.
- `BuildTime` 단위는 **초**다.

#### 발견 1 — 시간은 자유값이 아니라 공유 "사다리"다

1,975행의 BuildTime이 소수의 값에 몰려 있다:
`2, 3, 5, 10, 12, 15, 45, 47, 117, 176, 351, 702, 2106, 4212, 8424…`
(47이 38회, 117이 48회, 702가 41회 재사용). 대략 **×2 / ×3을 번갈아 가는 계단**이고
여러 건물이 그 계단을 공유한다.

→ 올림푸스도 건물마다 제각각인 숫자를 쓰지 않는다. 사다리
`0 / 2 / 5 / 10 / 15 / 45 / 120초`를 만들고 건물마다 **칸만 지정**한다.
그래야 나중에 기획이 곡선 전체를 한 번에 옮길 수 있다.

#### 발견 2 — 초반은 전부 "초" 단위다 (올림푸스가 틀렸던 지점)

튜토리얼 본부(생명의 묘목) Lv1~15가 전부 초 단위다:
목재 10 / 0초 → 20 / 3초 → 30 / 3초 → 200 / 10초 → … → Lv15 목재 1,800 + 금화 200 / 300초.
**본부 Lv5(702초)를 넘어서야 분 단위 대기가 시작된다.**

다른 건물 Lv1도 마찬가지로 싸고 빠르다 — 창고 목재 20 / 5초, 벌목훈련소 30 / 5초,
성벽 200 / 2초, 병영 500 / 2초, 금광 300 / 2초.

→ 고치기 전 올림푸스는 첫 건물이 45초~10분이었다. 뉴포리아 기준으로 **Lv4~6에 해당하는
수치를 Lv1 자리에 넣고 있었다.** 폐허 복구는 "Lv1 건설"이므로 그 대역으로 내렸다.

#### 발견 3 — 본부 레벨이 모든 것의 상한이다

- `BuildConditionList`에 `BuildFloatingIslandBuilding(1, N, false)`이 **1,105회** 나온다.
  즉 **모든 하위 건물의 최대 레벨 = 본부 레벨** (1:1 캡).
- 신규 건물 해금도 본부 레벨이다 — 병원 본부2, 금광 본부3, 길드 연회장 본부5,
  투기장 본부9, 대장간·던전 본부10, 전설의 전당 본부24.
- 본부 업글에는 추가 게이트가 붙는다(던전 N층 클리어, 특정 건물 레벨).
  본부만 올려서 건너뛰는 것을 막는 장치다.
- 가디언 최대 레벨 = 본부 레벨 × 5 (`ConstantData.CharacterLevelLimitCondition = "1,5"`).
