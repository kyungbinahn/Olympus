## 0. 무엇이 다른가 — 지금 vs 탑포스

| | 지금 올림푸스 | 탑포스(형님 관찰) |
|---|---|---|
| 시작 | 폐허 마을, 본부 복구부터 | **막사에서 시작, 처음부터 전쟁 중**. 지휘관(검은 왕)이 명령 |
| 싸움 | 도적이 2분 30초마다 한 번씩 | **전선에서 실시간 전투가 끊이지 않는다.** 적은 기지 안으로 안 들어온다. 다 죽어도 기지는 안 부서짐 |
| 병사 | 병영에서 식량·목재로 주문 → 끝나면 들어옴 | **장교가 있어야 뒷문으로 징집**이 계속된다. 징집병이 공방을 돌며 장비(소총·수류탄·탱크·약통)를 받아 성문 밖 전선으로 |
| 목표 | 본부 조건(번영도·건물·거인) | **적 전초기지를 하나씩 부순다.** 다음 기지는 더 세서 안 키우면 밀린다 → 본부 업·장비 업으로 유도 |
| 본부 업 | 토스트 한 줄 | **세레모니 창**: 전투력 오름 + 신규 건물·기능 안내. Lv.마다 **영토가 넓어지고 성벽이 바뀐다**. Lv.4는 깃발 꽂기 + 리뷰 요청 |
| Lv.3 사건 | 거인 1이 25분 뒤 도착, 300 vs 1 | 2차 기지 파괴 → **"강한 적 진격" 알림 → UR 영웅 맛보기 등장** → 대군 → 질 것 같은 순간 **적 지휘관과 대화 → 전투 맵으로 전환**. 전투 중 **게이지(명찰)가 차면 눌러서 병사 추가 투입** |
| 그 뒤 | — | 전선이 **한 방향으로 정리**, 적 기지가 반대편으로 옮겨 커짐, 우리 기지·성벽도 커짐. 맛보기 영웅 떠남. 적을 죽이며 자원, **적 기지·특수 병기를 누르면 전투 스테이지** |
| Lv.4~5 | 대기열 2·가방 / 신전·외출 | 헬기 등장, **영웅 모집**, "병력 부족" → 적이 밀려옴. **정찰하던 안내역이 붙잡힘 → 구출 미션(하루)** + 열쇠 모으기, 드론 정찰 = 감시 초소 소개 → Lv.5 |

## 1. 그릭로만으로 옮긴 흐름 (제안)

**세계(2026-10-23 형님 확정)**: 망한 세상 · 어두운 세상. 도적이 들끓고 **약탈이 일상**이다.
**주인공 = 지휘관**(백인대장급). **작은 폐허 마을에 막사를 지어** 장정을 모으고 **거병**해서 점점 커진다.
→ 폐허 마을(지금 기지)·복구는 그대로 살린다. 첫 건물이 **막사**이고, 막사가 서야 군대가 생긴다.

| 본부 | 장면 | 탑포스 대응 | 감정(컨셉) |
|---|---|---|---|
| Lv.1 시작 | 도적이 성문 앞을 서성이는 폐허 마을. 첫 임무 **막사 세우기** → 장정이 모여 거병, 곧바로 성문 밖에서 도적과 싸운다 | 처음부터 전쟁 | 위기 |
| Lv.1 | **뒷문으로 장정이 들어온다**(징집) → **창·방패 공방**에서 무장 → 호플리테스가 되어 성문 밖 전선으로. 공방을 올리면 더 빨리·더 세게 | 공장 고리 A | |
| Lv.1 | 첫 목표 **도적 소굴(전초기지 1)** — 전선 끝에 체력바 달린 건물. 부수면 갇혀 있던 **첫 영웅 구출**(예: 아이아스) | 빅터 구출 | 성취 |
| Lv.2 | **"거인 진영(전초기지 2)" 발견 + "적 접근 중 mm:ss"**. 활 공방(궁수), 치유의 집(약초 → 병사 체력↑) 열림. 장교(=백부장 휘하 **십인대장**)가 늘면 징집 속도·한 번에 나가는 수↑ | 레드 전초기지·구급키트·장교 | 시급성 |
| Lv.2→3 | 본부 업 **세레모니**: 전투력 ↑, 새 건물·기능 카드, 성벽이 나무 울타리 → 돌담으로, 바닥이 넓어짐 | 성벽 확장 연출 | |
| Lv.3 | 거인 진영 파괴 → **"거인 대군 진격!"** → **레오니다스(맛보기 UR)** 등장 → 거인 + 졸개 수십이 몰려온다 → 밀리는 순간 **거인 우두머리와 대화** → **협곡 전투 맵으로 전환 = 300 vs 1**. 전투 중 **함성 게이지**가 차면 눌러서 용사 추가 투입 | 대공세·나탈리·전투맵·명찰 게이지 | 희망 → 성취 |
| Lv.3 후 | 레오니다스 떠남("스파르타로 돌아간다"). 마을 환호. 전선이 **한 방향(협곡 쪽)** 으로 정리, 적 본진이 반대편에 더 크게. 적 본진·공성 병기를 누르면 **전투 스테이지** | 전선 재배치·스테이지 | |
| Lv.4 | 깃발(폴리스 문장) 꽂는 **큰 세레모니** → 기능 팝업 → 리뷰 요청. **기병(전차)** 등장, **신탁소(영웅 모집)** 열림. "병력이 부족하다" → 적이 밀려온다 | 헬기·모집 센터 | |
| Lv.4→5 | 정찰 나간 **안내역(예: 아리아드네)이 붙잡힘** → **구출 미션(하루)** + "제우스의 번개 조각" 4개 모으기. **아테나의 올빼미**로 정찰 → 감시탑 역할 소개 | 카시아 구출·핵무기 열쇠·드론 | 절망 → 도움 |
| Lv.5 | 월드맵(외출) 열림 | 레이더·월드맵 | |

이렇게 하면 컨셉의 "300 용사 → 거인 1"이 **탑포스의 Lv.3 대공세 자리**에 들어간다. 지금 1장(25분 카운트다운 + 출정)은
"거인 진영(전초기지 2) 접근 중" 타이머로 바뀌고, 출정 대신 **대공세 → 전투 맵 전환**으로 끝난다.

## 2. 시스템 — 새로 만들 것 / 바꿀 것

| 시스템 | 내용 | 지금 있는 것에서 |
|---|---|---|
| **상시 전선** | 성문 밖 한 방향에 늘 싸움. 적은 웨이브로 끊임없이 오고, 우리 병사는 공방에서 나온 대로 나간다. 기지 안으로는 안 들어옴 | 도적 습격(RaidService) → 끊김 없는 웨이브로 |
| **징집 흐름** | 뒷문 → 공방 줄 → 성문. 장교 수 = 동시에 걷는 줄 수. "병사 수"는 계산상 숫자, 화면엔 줄 선 병사 몇 명 | 병영 훈련 주문 → 공방이 자동으로 뽑는 방치형 |
| **공방 = 장비** | 창·방패 공방(호플리테스), 활 공방(궁수), 치유의 집(체력↑ 약초). 레벨이 장비 능력치 | 건물 레벨 → 전투 강화(battle.json buffs) |
| **전초기지** | 전선 끝 체력 있는 적 건물. 우리 병사가 닿으면 깎는다. 부수면 이야기·보상·다음 기지 | 새로 |
| **본부 세레모니** | 레벨업 창: 전투력 전후, 신규 건물·기능 카드, 성벽·영토 확장 연출 | 레벨업 토스트 → 전용 창 |
| **영토·성벽 확장** | 본부 레벨마다 기지 바닥이 넓어지고 성벽 모양이 바뀐다 | 격자 크기 고정(48) → 단계별 열림 |
| **전투 맵 + 증원 게이지** | 대공세 때 기지에서 전투 화면으로 전환. 게이지가 차면 눌러 병사 추가 | 협곡 300 vs 1(BattleArena) + 게이지 |
| **맛보기 영웅** | 한 번의 싸움만 빌려주는 강한 영웅 | 영웅 없음 → 첫 영웅 시스템 |
| **구출 미션** | 하루짜리 이벤트, 열쇠 모으기 | 새로 |

## 3. 순서 제안 (한 번에 다 못 한다)

1. **전선과 징집 (Lv.1~2)** — 성문 밖 상시 전투, 뒷문 → 공방 → 성문 흐름, 전초기지 1(도적 소굴) 부수기. *가장 먼저 "처음부터 전쟁 중"을 느끼게.*
2. **본부 세레모니 + 영토·성벽 확장** — 레벨업 창, 바닥 넓어짐, 울타리 → 돌담.
3. **Lv.3 대공세** — 거인 진영 접근 타이머 → 대공세 → 맛보기 영웅 → 전투 맵 전환(300 vs 1) + 증원 게이지 → 전선 재배치.
4. **Lv.4~5** — 깃발 세레모니, 전차·신탁소, 구출 미션·올빼미 정찰.

- 주인공 **백인대장** · 명령하는 **검은 왕** — 이대로? (검은 왕이 지휘관이고 우리가 그 휘하)
- 시작 화면: **폐허 마을 복구**를 버리고 **군영(막사)에서 시작**? 녹지 복구 연출(결정 A)은 영토 확장 연출로 옮겨 살릴 수 있다.
- 맛보기 영웅 = **레오니다스**? 첫 구출 영웅·안내역 이름.
- 1번(전선과 징집)부터 시작해도 되는지.

## 5. 진행 기록

### 2026-10-23 — 1단계 전선과 징집 (Core·월드 화면)

형님 결정: **군영에서 시작**, **전선과 징집부터**.

- **Core `FrontlineService`**: 전선 화력 = 건물이 주는 군대(battle.json army·buffs)의 초당 공격 × (0.5 + 0.5 × 체력 배수).
  적 기지는 체력·버팀을 갖고 **화력 − 버팀**만큼 초당 깎인다. 약하면 안 깎인다(밀림 → 키우라는 신호).
  피해 1000마다 목재 4·석재 3이 들어온다(적을 죽이며 자원). 생산과 같은 "정산 시각" 방식이라 앱을 꺼 둬도 싸운다.
  건물이 바뀌면 바뀌기 전 화력으로 정산하고 갈아탄다. 시험 8개.
- **적 기지 5곳** (`chapter1.json` frontline): 도적 소굴(Lv.1, 체력 9천·버팀 20) → 도적 요새(Lv.2, 2.4만·50) → 거인 진영(Lv.3, 10만·300)
  → 거인 성채(Lv.4, 20만·400) → 키클롭스 소굴(Lv.5, 40만·700). 무너질 때마다 보상·날개·이야기.
- **본부 조건**: Lv.2 = 번영도 3 + 도적 소굴, Lv.3 = 번영도 11 + 도적 요새, Lv.4 = 거인 격퇴(그대로), Lv.5 = … + 거인 진영.
- **도적 습격은 닫음**(raids.startHqLevel 99) — 전선이 그 역할을 한다(사방에서 오던 습격 → 한 방향 전선).
- **봇**: 본부 Lv.2 5.0분 · Lv.3 12.7분 · Lv.4 17.8분 · Lv.5 37.3분 / 도적 소굴 5.0분, 도적 요새 12.5분, 거인 진영 29.8분.
  탑포스 사람 기록(7·18·35·75분)을 봇 배율(약 1.5배 빠름)로 나누면 Lv.2~4는 비슷하고 Lv.5가 빠르다.
- **화면 `FrontlineDirector`**: 성문(위쪽 모서리) 밖 52m에 그레이박스 적 기지(도적 = 나무 울타리·망루, 거인 = 돌로 크게) + 체력바.
  뒷문(아래쪽 모서리)으로 장정이 들어와 병영·훈련장 앞을 거쳐 성문 밖으로 → 맞붙는 자리에서 적과 계속 싸운다(우리 8 · 적 6).
  깎는 속도가 빠를수록 적이 자주 쓰러지고, 밀리면 우리가 자주 쓰러지며 맞붙는 자리가 성문 쪽으로 당겨진다.
  무너진 기지는 가라앉고 다음 기지가 6m 더 멀리 선다. 협곡 300 vs 1 동안은 전선을 숨긴다.
- **HUD(전선 띠·무너짐 알림)는 HUD 세션에 요청** — 그쪽이 HUD 파일을 크게 고치는 중이라 겹치지 않게.

아직: 군영 시작 화면(막사·성문·뒷문만 있는 요새 — 지금은 폐허 마을 배치 그대로), 장교(징집 줄 수), 공방 = 장비, 세레모니(2단계).

### 2026-10-23 — 세계관 확정: 폐허 마을에서 막사를 지어 거병

- 막사(barracks)가 본부 Lv.0부터 열린다. 첫 임무 q00 "폐허 마을에 막사를 세워 군사를 일으키자".
- 군대의 첫 출처를 "기본 수비대 4명"에서 **막사(첫 4명 + 레벨마다 2명)** 로 옮겼다 — 막사가 없으면 전선 화력 0,
  도적은 성문 앞까지 오지만 성 안으로는 안 들어온다. 막사가 서면 뒷문으로 장정이 들어오기 시작한다.
- 이야기 hq1: "도적이 들끓는 어두운 세상, 약탈은 일상이 되었다… 이 폐허 마을에서 거병한다."
- 봇: 본부 Lv.2 4.7분 · Lv.3 14.0분 · Lv.4 19.2분 · Lv.5 37.8분 (도적 소굴 체력 9천 → 1.5만, 도적 요새 2.4만 → 3만으로 맞춤).
- 4절의 "군영에서 시작" 결정은 이것으로 바뀐다(군영 = 폐허 마을 + 막사).

- 둘레는 Core `WallRing`이 나눈다: 기둥 간격 4m, 사이마다 직선. **성문은 전선 쪽(+X+Z) 모서리를 비스듬히 자른 자리** —
  전선이 그 대각선으로 뻗어 있어 장정이 성문을 지나 곧장 나간다. L4·L5는 성문 모델이 없어 자리만 비어 있다(아트 B14 성문 예정).
- 연출(`TerritoryWallView`): 본부 레벨이 오르면 옛 성벽이 가라앉고, 새 성벽이 성문에서부터 둘레를 따라 양쪽으로 솟는다(약 3초).
  본부 레벨은 매 프레임 상태에서 읽는다 — 임무·디버그·세이브 어느 길로 올라도 같다.
- 앞뒤: Lv.2만 뒤집는다(버팀목·발판이 성 안쪽에 오게). 정한 근거는 위에서 본 사진.
- 남은 것: ① 성 밖 바닥이 성 안과 같아서 "땅이 넓어졌다"가 성벽으로만 읽힘 — 성 밖을 어둡게/황폐하게 할지 ②
  삼각형 수 — Lv.5 둘레가 조각 약 120개 · 50만 삼각형이라 모바일에선 합치기·LOD가 필요 ③ L4·L5 성문 ④ 세레모니 창(레벨업 카드).
