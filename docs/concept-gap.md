# 컨셉 ↔ 지금 만든 것 — 대조와 실행안

작성 2026-10-21. 기준: [`concept-core.md`](concept-core.md). 지금 상태: 본부 Lv.1~5([`progression-hq1-5.md`](progression-hq1-5.md)),
전선 스테이지([`battle.md`](battle.md)) — 둘 다 **탑포스 구조를 옮긴 것**이라 "무엇을 느끼게 하나"는 비어 있다.

## 1. 감정 구간별 대조

| 구간 | 컨셉이 원하는 것 | 지금 있는 것 | 비는 것 |
|---|---|---|---|
| 위기 | 행복한 마을, 가족·아이. 멀리서 거인이 주민을 짓밟으며 걸어온다. 절벽 구석에 몰린 마을 | 폐허 21채 기지(평지 가운데), 적은 전선 스테이지 안에만 있다 | 주민 NPC, **기지 밖에 보이는 거인**, 절벽 구석 지형 |

## 2. 방향이 다른 곳 (형님 결정 필요)

### A. 녹지 복구(영지 개간)
컨셉: "영지 개간도 소모됨 → **건축물 건설** 시뮬레이션". 지금 핵심 보상이 "폐허를 고치면 땅이 초록으로 번진다"인데,
이게 바로 개간 문법이다.
- 안 1: 녹지 번짐을 **배경 연출로만** 남기고(조용히), 건설·훈련·목마를 전면에.
- 안 2: 녹지를 빼고, 처음부터 **행복한 마을(완성된 건물 몇 채 + 주민)** 으로 시작. 폐허는 거인이 짓밟은 자리로만.

### B. 군대 = 건물 레벨 vs 병사 훈련
컨셉의 "300 용사"는 **사람 수를 세는 것**이 재미다. 지금은 건물을 올리면 병사가 저절로 생긴다.
→ 병사를 **훈련으로 만드는 자원**으로 바꾼다(병영에서 식량·목재 + 시간 → 호플리테스 N명). 건물은 훈련 속도·한도·강화를 준다.
탑포스도 Lv.7에 같은 구조(유닛 훈련 = 식량·철 소비처)가 있다 — 우리는 그걸 **맨 앞으로 당기는** 셈.

### C. 전선 스테이지 15칸(탑포스식) vs 사건 중심 챕터
지금은 `FIGHT 1~15` 사다리. 컨셉은 "거인 1 → 300 파견 → 거인 10 → 길드 → 요새"라는 **사건의 줄**.
- 안 1: 사다리를 버리고 **챕터 사건**(실시간 위협 + 목표 + 파견 + 연출)으로 교체.
- 안 2: 사다리는 "협곡 수비 훈련" 같은 보조 콘텐츠로 남기고, 큰 줄은 사건으로.

### 결정 (2026-10-21, 형님)
- **A. 녹지 복구는 그대로 쓴다.** 복구 = 보상 연출로 계속 간다.
- **B. 병사 훈련으로 바꾼다.** 병영에서 식량·목재 + 시간 → 호플리테스. 건물은 훈련 한도·속도·강화.
- **C. 사건 중심으로 교체.** 스테이지 사다리(1~15)는 버리고, "거인 접근(실시간) → 300 파견 → …" 사건의 줄로.

### 결정 (2026-10-23, 형님) — 정체성은 "방치형 → SLG"가 아니다
탑포스(출시 4개월, 구글 전략 매출 26위 전후·평점 4.5)의 반응이 형제작(화이트아웃·킹샷)만 못하다.
리뷰 불만은 전환 구조 자체보다 **전환할 때 속은 느낌**에 몰려 있다: "결국 또 킹샷이 된다", "광고와 다르다",
"초반에 남에게 연달아 털려서 지웠다", "아이콘만 누르다 결제벽".
- **정체성은 감정 흐름**(위기 → 희망 → 절망 → 안도 → 복수)이다. SLG 기능은 시스템이 바뀌어서가 아니라
  **이야기가 필요를 먼저 만든 뒤**에 연다(거인 10마리 → 길드, 근거지 → 목마·영웅).
- 탑포스에서는 **장치만** 빌린다(퀘스트 바·가속권·기능 단계 해금). 방치형 앞부분을 내세우지 않는다.
- **초반에 "자리를 비운 사이 뺏겼다"를 주지 않는다.** 도적 습격(`chapter1-300.md`)은 지금 쉬워서 괜찮지만,
  숫자를 올릴 때 이 선을 지킨다(예: 꺼져 있을 땐 무조건 막아 냄, 뺏김은 보고 있을 때만). PvP는 5등급 요새부터.
- 광고 장면은 **게임 안에 실제로 있는 것**으로만(300 vs 1 협곡).

## 3. 그대로 살리는 것
- 상태 변경 한 길(`StateDelta`), 끝나는 시각 타이머 → **거인 도착 카운트다운이 그대로 들어간다**
- 본부 레벨·건물 업그레이드·생산/수확·가속(헤르메스의 날개)·임무 바·기능 해금 표 → 챕터 뼈대
- 결정론 전투 시뮬레이션 → 300 vs 1도 같은 엔진(300명은 성능상 **분대 단위**로 묶어 그리는 게 현실적)
- 목마 건조장(B16) 아트·자리, 월드맵 생성

## 4. 1장 "300 용사" 실행안 (A·B·C 결정 후)

**2026-10-22 진행: 2~5번 완료** — [`chapter1-300.md`](chapter1-300.md). 남은 것: 1번 오프닝 연출, 5번의 환호 연출, 6~7번.

| 순서 | 만드는 것 | 감정 |
|---|---|---|
| 1 | 오프닝: 절벽 구석 마을 + 주민(가족·아이) → 카메라가 멀리 빠지며 지평선의 거인 | 위기 |
| 2 | 장로/지휘관 대사 "좁은 협곡에서 300 용사로" → 상단에 **용사 0/300**, **거인 도착 HH:MM** | 희망·시급성 |
| 3 | 병사 훈련(병영): 식량·목재 + 시간. 임무 바가 농장·목공소를 시킨다 | 시급성 |
| 4 | 거인이 기지 밖 배경에서 실시간으로 다가오는 것이 보인다(시간에 연동) | 시급성 |
| 5 | 300 달성 → 협곡으로 행군 → **300 vs 1** 전투 → 마을 환호 | 성취감 |
| 6 | 거인 10마리 → 길드 가입(가짜 길드원) → 목마 지원 도착 | 절망 → 안도 |
| 7 | 목마 건조 + 첫 영웅(아킬레우스) → 1등급 요새 집결 | 복수 |
